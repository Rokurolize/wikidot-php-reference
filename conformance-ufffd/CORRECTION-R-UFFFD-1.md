Reference correction for R-UFFFD-1 (2026-11-22). Downstream of the live-true `pre()` conversion, a literal U+FFFD in post-parse text becomes a delimiter byte and the fossil render loop in `ref-php/text-wiki/Text/Wiki.php` calls `token()` on a null renderer (`Error: Call to a member function token() on null` on 29 of the 30 literal-segment cases in conformance-ufffd/, and the garbled `<p>alpha <strong>bold</strong> <p>1` on end-after-bold). Live recovers the text and leaks token indices. The change is confined to `Text/Wiki.php`: when the post-parse source contains a literal U+FFFD, `render()` takes `renderLiteralUfffdRecovery()` instead of `pre()` plus the character loop. The escaping is the same `htmlspecialchars` / `htmlentities` call `pre()` makes, but each delimiter byte is marked as an original placeholder or a literal character before the escape, so the two stay distinct. An original `⟨digits⟨` placeholder still renders. One literal delimiter immediately in front of a placeholder leaks that token's fresh-document index and does not render it; a second placeholder with nothing between them is swallowed the same way and its index is leaked too, which merges the adjacent blocks. Any other literal delimiter is dropped. Two or more literal delimiters in a row are dropped without a leak, and the following placeholder still renders. The fragment then goes through the live `purifyHtml` tidy repair (wrap, HTML Tidy 5.8.0 invoked as `tidy -q -utf8 --doctype strict --indent no --output-xhtml yes --wrap 0`, body extracted and trimmed the way the page-content capture is stripped). Tidy closes an open paragraph, removes an empty paragraph, drops a stray end tag, collapses the space a dropped character left between words, and turns a paragraph end trapped inside a heading into `<br />\n<br />`. Documents with no literal U+FFFD in the post-parse source take the original loop unchanged, so the token counter is untouched. The fresh-document index used for a leak is `id - firstId + 1`: a fresh reference document numbers the paragraph-end token 1, and live serves 2 for that same placeholder. The pre-correction file is `ref-php/text-wiki/Text/Wiki.php.before-ufffd.php` (SHA-256 a827c9ac5f26a4ee8493e3148d51f9e701a17a575ae682c1d9533036bdfbff5f). Verification, through `ref-php/harness/batch.php` render on PHP 8.5.4, one process for the whole family: the 30 literal-segment cases now equal the live captures exactly, and the six cases with no literal U+FFFD in a text segment are byte-identical to the previous reference output. The after-renders are `conformance-ufffd/ref-renders-after.jsonl`.
