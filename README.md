# wikidot-php-reference

A standalone, runnable PHP reference implementation of Wikidot's wikitext parser, behavior-corrected rule by rule against the live Wikidot service. It exists to serve as an executable specification of how live Wikidot actually parses wikitext: the corrections are not taken from the old source code's authority but are validated, one rule at a time, against live behavior, with the differential evidence kept in `conformance/`.

This repository is a snapshot publication. Development happens in the ftml Lean equivalence proof loop's working copy (the loop proves, in Lean, that the Rust parser [ftml](https://github.com/Rokurolize/ftml) matches Wikidot's parsing semantics); tagged snapshots are pushed here as correction stages complete.

## Provenance and a warning

The code derives from the Wikidot 1 open-source release (mirrored at [gabrys/wikidot](https://github.com/gabrys/wikidot)), principally its vendored Text_Wiki library, which applies roughly 70 parse rules in sequence. That upstream code is a fossil from the late 2000s and early 2010s: it is the skeleton of this reference, never evidence for how the live service behaves today. Several fossil behaviors have already been refuted by live probes during correction (the Include rule's scanner shape, its reference resolution, and Prefilter's character stripping among them). Trust a rule in this tree as live behavior only where the status table below says it has been corrected and validated. This project is not affiliated with Wikidot.

## Layout

- `text-wiki/`: the working copy of the Text_Wiki library (parse and Xhtml render rules), modernized to run on PHP 8 and corrected per the status table.
- `wikidot-root/`: the minimal reconstructed runtime root the library expects (WDStringUtils, Text_Highlighter, a small PEAR shim, parser configuration).
- `harness/`: command-line drivers. `transform.php` renders wikitext from stdin to Xhtml (or dumps the parse-phase token array). `batch.php` is a JSONL batch driver with three modes: `expand` (Include rule only, the expansion-level view), `render` (full pipeline), and `tokens`. Pages are served from an in-memory map in `harness/pages.php` through the stubs in `harness/ozone-stubs.php`; no database or web server is involved.
- `conformance/`: the differential records behind every correction (inputs, live captures, result catalogs).
- `docs/INVENTORY.md`: the correction plan and per-phase record. `docs/r1-compat.patch`: the mechanical PHP 8 compatibility patch that made the fossil runnable, kept for provenance.

## Correction status

- **R1, runnable skeleton: done.** The fossil runs on PHP 8.5 with only mechanical, semantics-preserving edits (constructor renames, by-value `process()` signatures, bracket string offsets), plus one flagged era-semantics bridge in the Xhtml render pre-pass (ENT_SUBSTITUTE) whose adjudication is recorded as an open item.
- **Include: corrected and validated.** The fossil's regex scanner was replaced with a hand scanner implementing the adjudicated grammar (line-start anchoring, quoted-include consumption, the argument grammar), and a reference-resolution layer was added (normalization, site handling, cross-site fetch), including the completed live resolution rule for colon-edge targets (a character-set gate on page names and on a site pair's page segment, measured across 31 probed shapes). Its argument substitution fold matches live behavior on all 14 probed cases. In the final three-way differential over a 119-case grid, the reference and ftml agree on 104 cases textually and on all but the includer-surface cases in disposition, with zero resolution divergences in either direction.
- **Code: corrected and validated.** The parse rule needed no behavioral correction. The Xhtml render rule took five corrections: instantiating the syntax highlighter factory (the fossil's static call is a fatal error on PHP 8), a bare wrapper element for empty bodies, a line-wise body trim that keeps first-line indentation (with NBSP served as a regular space), PHP 4/5-era escaping defaults (apostrophes stay literal), and the newline live emits after the wrapper's opening tag. The corrected rule's rendered code fragments are byte-identical to live captures on all 15 probed cases, highlighted output included, and match all 37 in-scope ftml corpus pins.
- **Url, Email, Mathinline, Interwiki: corrected and validated.** The inline family opens here. Url gained Wikidot's extra autolink schemes and learned to stop at an inline-math opener; an attempt to split link targets at pipes the way ftml does was tried and reverted on fresh live evidence, confirming the pipe stays in the target. Email needed no correction: the described-address form that looks like an extension is genuine live behavior. Mathinline now resolves earlier-rule placeholders inside its body the way live does and renders the deterministic span live serves instead of the fossil's generated-image path. Interwiki needed no rule change either; only its configured URL templates moved to https. Seven divergences in ftml were cataloged along the way.
- **Colortext, Strong, Emphasis, Underline, Strikethrough: corrected and validated.** Colortext's renderer dropped the trailing semicolon in its style, replaced the fossil's sixteen-name color whitelist with the normalization ftml and live share (hex, rgb(), var() and arbitrary names, with out-of-class specs falling back to literal text), and renders a whitespace-only color field without the space after the colon. Strong and Emphasis learned the empty-pair behavior live shows (a bare **** or //// pair is consumed, not left literal), Emphasis now pairs first-fit the way live does, and Underline deletes an adjacent empty __ pair outright instead of letting one marker serve as the other's body. Strikethrough needed no correction at all. This snapshot also carries a Url renderer correction from the same round: live percent-encodes non-ASCII bytes in autolink hrefs, and the renderer now does the same. Six divergences in ftml were cataloged along the way.
- **Tt, Superscript, Subscript, Typography, Tighten: corrected and validated.** Tt now hoists leading and trailing padding out of the monospace container and suppresses empty, padding-only and zero bodies instead of emitting an empty element. Superscript consumes a bare empty pair rather than leaving it literal, and Subscript takes its empty-pair alternative at the earliest position the way live's first-fit pairing does. Typography needed no correction at all: its entity table (dashes, ellipses, quotes, guillemets, the non-breaking space in number-and-unit shapes) is already what live emits. Tighten, the final output-shaping pass, folds residual whitespace runs, hoists a leading space out of a color span and ejects a trailing one, and trims single spaces at paragraph and line-break edges. Six divergences in ftml were cataloged along the way (comma-run subscript pairing, two empty-pair line-break shapes, a pipe split inside a subscript label, curly quotes ftml substitutes where live leaves them literal, and an autolink that swallows a non-breaking-space boundary).
- **Image, Newline, Paragraph: corrected and validated.** Images gained live's attribute order, title emission, and non-ASCII encoding, and stopped swallowing their caption closers. Newline needed no correction at all: live emits the same self-closing break form the fossil has, which settles the break-spelling question that runs through the whole corpus. Paragraph learned the one form it was missing, the scored span opener that suppresses its own wrapper. Two long-open questions closed here: the flow-text space collapse belongs to the HTML purification stage, not to Paragraph, and the score-span suppression applies only to the scored opener form. Eight divergences in ftml were cataloged along the way.
- **Table and Tableadv: corrected and validated.** The simple table lost its pretty-print indentation and stray tag spaces, and an entirely empty row now yields one plain cell. The advanced table form was rebuilt around how live actually validates it: only row blocks inside the table and cell blocks inside rows, header-ness decided by the closer name, attributes filtered through the safe allowlist with isolated ids, and nested tables tokenized before the outer split. Six divergences in ftml were cataloged along the way, including two attributes live drops from cells that ftml keeps. This snapshot also carries a small List renderer correction (the depth-skip wrapper newlines) that followed from a parity-side confirmation after the List snapshot.
- **List and Deflist: corrected and validated.** Lists now drop empty items and empty containers the way live does, open one inline wrapper per skipped nesting level, and lost their pretty-print indentation. Deflist's real form turned out to be the colon-led line (the semicolon form is literal text on live), and it no longer emits empty definition lists for separator-less lines or empty terms. One whitespace question inside skipped-depth list wrappers is cataloged against ftml's pins, and one gap is the reference's own: it has no rule yet for ftml's explicit [[ul]] block form.
- **Container family (Span, Size, Div, Collapsible, Tabview): corrected and validated.** Span gained live's full attribute whitelist with its id isolation and stopped stripping hidden styles; Size now cleans its body the way live does and drops empty sizes inside-out; Div recognizes the scored [[div_]] opener at last and suppresses empty attributeless divs; Collapsible's whole frame was rewritten from the fossil's id-and-onclick form to the class-based frame live actually serves; Tabview normalizes and escapes its tab labels. Six divergences in ftml were cataloged along the way, mostly around size-value grammar and malformed container shapes.
- **Blockquote, Heading, Toc: corrected and validated.** The [[blockquote]] block form turns out to be literal text on live (only the >-prefixed lines form quotes), and the blockquote rule now drops empty quote containers and lays out nested quote endings the way live does. Headings gained the no-table-of-contents * form, which renders without an anchor and is excluded from the toc, and now consume the whole whitespace run after the level prefix. The toc box itself reads Fold and Unfold capitalized, honors its title attribute, and no longer leaves a stray space in its float class. Two divergences in ftml were cataloged along the way (a pipe inside a double-bracket link target, and raw dashes in toc labels where live emits entities).
- **Footnote and bibliography family: corrected and validated.** Footnote and Bibcite needed no correction; the fossil already matches live on numbering, collection, and citation resolution, including duplicate labels resolving to the last entry. Footnoteitem and Bibitem no longer leave a stray separator space on empty bodies, Footnoteblock escapes its title the way live does on modern PHP, and Bibliography's body layout was rewritten to keep non-definition lines in place instead of flattening the whole body onto one line. Nine divergences in ftml were cataloged along the way (quote serialization across the family's anchors, a mixed-case footnote closer, bibcite separator strictness in both directions, and three bibliography shapes).
- **Concatlines, Freelink, Equationreference: corrected and validated.** Concatlines no longer fuses a standalone [[div]] opener into the preceding paragraph when a continuation precedes it. Freelink took seven corrections: anchors with digits are kept and appended in both the existing-page and new-page branches, labels may contain further pipes, the fossil's cross-site split that crashed on modern PHP is gone, leading underscores and category prefixes survive, URL targets and hash routes are recognized, non-ASCII targets are transliterated, and a leading colon or slash survives in the display text. Equationreference needed no correction at all: the fossil already matches live on every probed shape, including forward references, duplicate labels, and undefined labels. Nine divergences in ftml were cataloged along the way, most of them around where ftml's preprocessing joins continued lines before its rules ever see them.
- **Iftags, Comment, Iframe, Date, Math: corrected and validated.** Iftags tag comparison is now case-insensitive, as live is. Comment keeps an indented comment alone on a whitespace-only line from collapsing the line structure. Iframe lost a stray space before the closing bracket of its tag, percent-encodes non-ASCII source bytes, strips line breaks from a greedy source tail, and leaves single quotes literal. Date now emits live's odate span shape with canonical classes, accepts negative timestamps, and renders blank values as nothing. Math's \include/\input guard compiles again under modern PCRE and an immediately adjacent closer terminates the block. Twelve divergences in ftml were cataloged along the way (comment/iftags pairing, iframe tail and quoting, iftags spec splitting, date blanks, math attribute keys, and one math guard case live's save filter would not let us probe).
- **Modulepre, Module, Module654: corrected and validated.** Modulepre (the prefilter that rewrites line-start [[module654]] openers to [[module]] before block matching) needed no correction; live confirms the fossil's rewrite, name charset, and claiming behavior. Module's unknown-module error block now carries live's current wording ("No such module, please check available modules and fix this page", settled byte-for-byte by probes), and an empty module body no longer consumes its [[/module]] closer. Module654 now claims an opener with trailing spaces before its newline, as live does. The stage also cataloged six places where ftml diverges from live (module name validation, the missing prefilter rewrite, trailing-whitespace openers, a rel attribute on the error link, empty-body closer consumption, and module body ownership). Module evaluation itself (what ListPages or Rate compute) is a serving-layer concern, out of scope here.
- **Form, Raw, Rawold: corrected and validated.** Raw's parse rule was rewritten as a scanner implementing live's run arithmetic for adjacent @ signs (runs vanish, leave literals, or form a raw span, including the cross-line forms), and its render rule now emits live's pre-wrap span with the Wikidot raw escape table (spaces as &#32;, apostrophes literal). Rawold (the double-backtick raw form) needed no correction. Form's fossil backend is absent from the snapshot and fataled; live renders a matched [[form]] block on an anonymous page view as literal source text, and the rule now reproduces that display shape (the interactive form itself is a serving-layer concern). The corrected rules match all 24 non-surface live probes byte-for-byte; the stage also cataloged five places where ftml itself diverges from live (no Rawold rule, no [[form]] rule, apostrophe escaping in raw spans, a link-boundary interaction, and an angle-raw extension live does not have).
- **Prefilter: corrected in part.** Its tab expansion and newline compression are confirmed live; its stripping of a specific two-character sequence was refuted by a live probe and has been removed.
- **Delimiter: dispositioned.** It guards the library's byte-oriented token encoding against forged delimiter bytes, which typed UTF-8 text cannot contain; it has no observable behavior and no counterpart in ftml.
- **All 68 active rules: validated.** With the paired-marker tail complete, every active rule in the pipeline has been differentially validated against live behavior. The disagreements that remain are cataloged in `conformance/`: divergences in ftml itself, frame-level surfaces owned by the HTML purification stage rather than any single rule, and stated coverage gaps where a shape could not be probed.

## Running it

Requires PHP 8 (developed and tested on PHP 8.5). From the repository root:

```
php harness/transform.php render < page.wikitext
printf '%s\n' '{"id":"x","source":"Hello **bold** world."}' | php harness/batch.php render
```
