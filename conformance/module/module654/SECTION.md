## Mechanism as corrected

The parse rule (ref-php/text-wiki/Text/Wiki/Parse/Default/Module654.php) matches a line-start [[module654 NAME attr]] block, with case-insensitive names in [a-z0-9_\-\/]+, an optional raw attribute string, a newline after the opener, and an optional body closed by [[/module]], then emits "\n\n".addToken(...)."\n\n" with trimmed moduleName, attr and body. The one correction is that the newline after the opener now accepts trailing horizontal whitespace: the regex changed from \]\]\n to \]\][ \t]*\n, mirroring the sibling Module rule's " *\n". The decisive evidence is saved page muse-probe-r2mod-module654-p-upper-newline-spaces, whose source [[MODULE654 CSS]]   \n.upper-live-green { color: green; }\n[[/module]] claims the block live (the page content is empty because CSS goes to the head), while the pre-correction reference left it literal; only Module654 can fire there because Modulepre's rewrite is case-sensitive. Isolated token dumps confirm the corrected rule now produces Module654 tokens for m654-newline-spaces and m654-newline-tab-space and still refuses m654-newline-none. The render rule (Render/Xhtml/Module654.php) is unchanged: it extends the Module renderer, so the live unknown-module error-block correction in that parent also applies to module654 names. Verified unchanged against live, with no correction made: the fossil name charset is right (live claims leading-digit 123abc, digits-only, slash foo/bar, and leading - or _ as unknown-module error blocks), uppercase and mixed-case openers claim live, [[/module]] is the closer while [[/module654]] stays literal in the body for both lowercase and uppercase openers, no-newline with trailing text stays literal, and an invalid class="" head stays literal.

## Corrections made

C1 (fossil-era artifact). The fossil required a newline immediately after the module654 opener, while live also claims an opener whose line ends with trailing horizontal whitespace before the newline. Replaced \]\]\n with \]\][ \t]*\n in the parse regex; this moved the battery from 10 exact / 34 serving-layer surface / 15 substantive to 12 / 34 / 13 and made the corrected reference agree with live on the spaces-before-newline probes. No reference bug, PHP-version artifact or harness matter was found in either of this rule's files, and the render file needed no change. Pre-correction bytes are preserved as Module654.parse.before.php and Module654.render.before.php; the render copy is byte-identical to the current file. The error-block strings in ref-render-before.jsonl are stale relative to the sibling Module render edit at 11:33, so ref-render-final.jsonl is the reporting basis for battery numbers.

## Remaining disagreements, dispositions, and candidate findings

Class S (frame-level surface owned by later rules, not Module654 divergences): the \xFE marker versus ftml's TODO placeholder or style output versus live's real module widget (probes p-lower-name-upper, p-control shapes, p-lower-closer-module), the <br /> against <br> and non-breaking-space differences, and the extra newline the live page keeps between an error block and a following paragraph (probes p-lower-closer-654, p-upper-basic, p-mixed-basic, p-upper-closer-654). F1 (candidate ftml divergence): ftml rejects module names with a leading digit or internal slash where live and the reference claim them (battery cases m654-name-leading-digit, m654-name-slash; probes p-lower-leading-digit, p-upper-leading-digit, p-lower-slash, p-upper-slash); the source is wikidot_valid_module_name in ftml's module/rule.rs. F2 (candidate ftml divergence): ftml leaves an opener with trailing spaces before the newline literal where live claims it (battery m654-newline-spaces, m654-newline-tab-space; probes p-lower-newline-spaces and the decisive p-upper-newline-spaces); the corrected reference now agrees with live and this was C1. F3 (root cross-rule, Modulepre-owned): for unmatched inline and tail forms the live prefilter rewrites module654 to module while ftml preserves the module654 spelling (battery m654-body-inline, m654-body-inline-empty, m654-vs-module-tail, m654-vs-module-sameclose; probe p-lower-inline-body). F4 (root cross-rule, Module-owned): for an empty body with an explicit closer, live and ftml leave [[/module]] literal while the reference consumes it (probe p-lower-empty-body). F5 (surface): \xFE marker versus ftml TODO/style and the frame whitespace above. No ftml file was edited.
