# ADJUDICATION C-SUSPECT-RAWHEAD-5 — authored `üü` in a heading corrupts the reference TOC (REFCORR3 lane, 2026-11-22)

Status: ADJUDICATED, deliberately NOT corrected. The SUSPECT-RAWHEAD lane confirmed the divergence with the valid, stable, saved-source-matching capture muse-probe-suspect-rawhead-toc-umlaut (source `+ aüüb\n[[toc]]`; html_sha256 0f7324cb0adb53596cba23c74a8a72f8507fd7a04ce52d736338ffe23a824a69). Live serves `<h1 id="toc0"><span>aüüb</span></h1>` and a complete TOC list with `<a href="#toc0">aüüb</a>`; the reference produces a label with the `üü` gone and most of the TOC chrome swallowed by `strip_tags`. The capture is decisive but does not make a single correction location unambiguous, so BRIEF-REFCORR3's fallback applies: the two candidate fixes are costed here and no one-sided patch is adopted.

## The mechanism and the two candidate locations

Render/Xhtml/Toc.php's item_start/item_end wrap every label in a literal `üü` pair (`utf8_encode("\xFC")` twice). Text/Wiki.php's post-render pass then applies `preg_replace_callback("/üü(.*?)üü/s", 'strip')` over the whole final HTML. An authored `üü` inside the heading label becomes the opening delimiter and the Toc-emitted pair becomes the closing one, so strip_tags deletes everything between them. Candidate A (Render/Toc.php alone): choose a different printable sentinel — one file, but not durable: the lane's S9 established that arbitrary Unicode including `ü` can be saved in headings through live's UTF-8 save layer, so any in-band printable sentinel is forgeable. Candidate B (Text/Wiki.php alone): keep the `üü` delimiter but anchor the regex to TOC structure — one file, but the post-pass receives only the final HTML string with no provenance to tell an authored `üü` from an emitted one; the anchored pattern is a brittle HTML parse and still misfires for a marker inside the list. The minimal robust fix is a third option requiring both files: change the sentinel in Toc.php and Wiki.php together to an out-of-band NUL-bearing sequence, which the lane's S9 showed cannot be authored through the save path. Cost: two files, two before-copies, one CORRECTION record, and the mirror restatements below. That option is recorded for a future lane; this lane does not adopt it.

## Mirror assessment (either way)

The reference's sentinel is mirrored in lean-ftml/LeanFtml/RenderCore.lean as tocStripDelim (line 486) and postStripToc (line 520), applied in the render pipeline at line 615; RawHeadingRules.lean's renderToc emits tocStripDelim at item_start/item_end, and RawHeadingRender.lean's toc_item_start_level and toc_item_end_shape pin those bytes. Changing the delimiter would require restating those four theorem families plus RenderCore's postStripToc_strips_tags and postStripToc_no_c3 and NotesRender's postStripToc_of_all_ne_c3. No mirror edit is made here: the mirror faithfully transcribes the uncorrected reference, and the adjudication is that no one-sided change is safe.
