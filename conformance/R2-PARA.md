# R2 Image, Newline, and Paragraph stage: differential and correction catalog (2026-11-20)

Method. This stage runs as a team of three rule owners plus a root coordinator, one owner for each of the thirty-seventh through thirty-ninth pipeline rules in this batch: Image, Newline and Paragraph. The loop is building a PHP reference implementation that reproduces live Wikidot behavior, the fossil Text_Wiki snapshot corrected rule by rule against live evidence: the fossil is a skeleton and never evidence, live Wikidot behavior is definitionally correct, and the evidence order is ftml corpus pins first, then frozen captures, then live sandbox probes, with fetching from live pre-approved and cached once. Earlier stages are published as the catalogs conformance-refphp/R2-INCLUDE.md, R2-FRAME.md, R2-CODE.md, R2-FORM-RAW.md, R2-MODULE.md, R2-NEXT.md, R2-LINK.md, R2-NOTES.md, R2-BLOCK.md, R2-CONTAIN.md, R2-LIST.md and R2-TABLE.md, and this catalog imitates their shape. Each owner reads its rule's parse and render files and the corresponding ftml behavior, builds an at-least-40-case whole-document battery covering its matching space, runs the reference before and after correction through the shared harness (ref-php/harness/batch.php, modes render and tokens) and the stage's shared ftml dumper (conformance-refphp/para/rust-dump/, preprocess_for_layout, tokenize, parse, HtmlRender over JSONL {"id","source", optional "tags"} at the read-only ftml checkout HEAD recorded beside it), probes live under its disjoint prefix (muse-probe-r2para-img-, muse-probe-r2para-nl- and muse-probe-r2para-pg-), corrects only its own two rule files while preserving the pre-correction bytes as <rule>/<File>.before.php, classifies every correction and every remaining disagreement, and writes its SECTION.md ending in COMPLETE or BLOCKED:. The root owns the shared harness and dumper, the two routed open items (the frame stage's paragraph space-run collapse and the CONTAIN stage's score-span paragraph suppression, both settled by the Paragraph owner with root adjudicating any interaction-level remainder), the Newline rule's <br> versus <br /> spelling surface, the cross-rule interactions (probed under muse-probe-r2para-x-), the catalog, and the final nine-case smoke run; the root does not do an owner's rule work except where an owner leaves it unfinished and the catalog says so. Serving-layer scope applies as in earlier stages: image attachment existence and file serving are serving-layer, while this stage owns the image syntax, its attribute grammar and the observable tag shape for the URL forms live accepts. Standing rules for the whole team: make no git commits in this worktree, set no git identity variable or -c user.* override, keep the ftml checkout read-only, write prose as flowing paragraphs on single lines, and run cargo only through heavy-build.sh with HEAVY_BUILD_NO_SPLIT=1 as a polled background job.
