The fossil's ref-php/text-wiki/Text/Wiki/Render/Xhtml/Bibliography.php escaped the title with a bare `htmlspecialchars()` call, which defaulted to ENT_COMPAT before PHP 8.1 but defaults to ENT_QUOTES|ENT_SUBSTITUTE since, so on the harness's PHP 8.5 the reference emitted `It&#039;s fine` instead.
