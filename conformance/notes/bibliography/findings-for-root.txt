R2-notes Bibliography: candidate findings routed to the coordinator. Proposed M-numbers start at M30 because M28 and M29 may be reserved by other owners in this stage; root assigns the canonical number. No ftml file was edited. All probes named below are run-owned pages on sandbox-for-codex under prefix muse-probe-r2notes-bib-, double-fetched anonymously, with stable=true, saved_source_matches=true and valid=true; captures are cached in probe-captures.json and probe-captures2.json.

BIB-F1 (proposed M30), live-backed candidate ftml divergence: with an explicitly empty title argument, [[bibliography title=""]], live omits the title div entirely, rendering <div class="bibitems"><div class="bibitem" ...>, while the ftml dumper emits an empty <div class="title"></div> before the first entry. The corrected reference matches live. Evidence is valid probe p03 (muse-probe-r2notes-bib-p03-title-empty, capture html "<div class=\"bibitems\">\n<div class=\"bibitem\" id=\"bibitem-1\">1. Entry A.</div>\n</div>"), battery case bib15-title-empty with ref-render-after.jsonl and ftml-dump.jsonl, and ftml's src/render/html/element/bibliography.rs render_wikidot_bibliography_shell which emits the title div unconditionally for legacy layout.

BIB-F2 (proposed M31), live-backed candidate ftml divergence: consecutive non-definition lines inside a bibliography body are joined with a single space on live and in the reference, while ftml drops the separator. Live probe p17 renders "plain line one plain line two" and p18 renders "first prose second prose" as one residual text run; battery case bib35-line-anchored-list gives reference "* item one * item two" against ftml "* item one* item two". The frozen live pin test/misc/bibliography-tab-gap/wikidot.html independently shows ": bell : Bell text. :cyd : Cyd text.". The reference is live-correct here and no correction was made.

BIB-F3 (proposed M32), candidate ftml divergence in the footnote family, attributed to the footnote owner for routing: when a footnote is opened inside a bibliography body and closed after the block, live and the reference put a space before the attached footnotes footer ("after <div class=\"footnotes-footer\">") while ftml emits no space ("after<div class=\"footnotes-footer\">"). Evidence is valid probe p13 (muse-probe-r2notes-bib-p13-footnote-open) and battery case bib48-footnote-opened-in-bib-body. The bibliography region and entry numbering agree on all three sides; only this tail boundary differs.

Correction routed to the Bibitem owner, not an ftml finding: an empty definition value such as ": e :" renders "4. " with a trailing space in the fossil Bibitem render, while live, the ftml dumper and the frozen pin test/misc/bibliography-definition-separators/wikidot.html render "4." with no trailing space. Evidence is valid probe p06 (muse-probe-r2notes-bib-p06-separators) and battery case bib38-definition-separators. The fix belongs in ref-php/text-wiki/Text/Wiki/Render/Xhtml/Bibitem.php, which is outside this rule owner's scope.

Harness matter routed to root, not a rule correction: ref-php/harness/batch.php sets $wiki->vars['page'] only when a case's tags array is non-empty, so an untagged or tags:[] case leaves the Iftags rule with no page object and it drops the gated body before Bibliography runs. With tags:["unrelated"] the reference renders both iftags cases exactly as live does. Evidence is battery cases bib51-iftags-kept and bib52-iftags-closer-inside, valid probes p11 and p12, and a local A/B test where tags:[] yields an empty bibliography region but tags:["unrelated"] yields the live-matching region. Root owns batch.php; no harness file was edited here.

Frame-level and other-rule surfaces kept out of the candidate list: the random suffix and apostrophe escaping in bibcite ids (Bibcite render owner, related to the already-routed M22), the empty style attribute on a bare [[span]] (Span render owner), numeric entity vs literal em dash and ellipsis (Typography render owner), the internal whitespace of a rendered table (Table render owner), and the paragraph/deflist wrapper and newline differences outside the bibitems region. Each is confirmed by a live probe to be a frame or later-rule surface rather than a Bibliography divergence.
