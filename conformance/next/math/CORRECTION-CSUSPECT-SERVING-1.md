# CORRECTION C-SUSPECT-SERVING-1 — Math environment type (REFCORR3 lane, 2026-11-22)

Status: APPLIED in this tree. The reference's Math parse rule silently mapped every non-whitelist type (including absent, empty and upper-case) to `equation`, and its render emitted only equation*/eqnarray* envelopes. Live preserves any lower-case environment name, defaults an absent type to `align`, rejects an empty or upper-case type with an "Unsupported math environment" error block, and still advances the equation counter for rejected blocks. Candidate C-SUSPECT-SERVING-1 is recorded in GAP-LEDGER.md and REPORT-SUSPECT-SERVING.md.

## The correction (reference)

Render/Xhtml/Math.php: a value not matching `^[a-z][a-z0-9]*$` returns `<div class="error-block">Unsupported math environment "<type>"</div>`; the envelope passed to LatexRenderer becomes `\begin{TYPE} <content> \end{TYPE}` from the chosen type.
