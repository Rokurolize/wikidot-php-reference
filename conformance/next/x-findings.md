Root also created two tagged kept-body probes under the same x- prefix with site.page.publish(tags=["alpha"]) through the pinned wrapper (probe-x-tagged.jsonl, probe-x-tagged-map.json, captures-x-tagged.json, x-ref-render-tagged-final.jsonl, x-ftml-dump-tagged-final.jsonl; all valid, stable and source-matching). Both confirm that a true Iftags gate keeps the body and that its inner Math and Module constructs are then evaluated: live renders the real equation and the no-rel module error block, the reference renders the same module block and the stubbed Math failure path, and ftml renders the same equation and the already-routed rel-bearing module block. Suppression and keep polarities are therefore both settled live in root's own evidence.

Root owns the seams the five per-rule batteries cannot own. The battery is conformance-refphp/next/xmake_battery.py generating xbattery.jsonl (33 cases), with reference and ftml outputs in x-ref-render-pre.jsonl and x-ftml-dump-pre.jsonl at the read-only ftml HEAD 97bed049d; the focused live probe set is probe-x-cases.jsonl, probe-x-map.json, captures-x.json (12 saved anonymous page views under muse-probe-r2next-x-, all valid, stable and saved_source_matches=true). The exact probe sources were also run through both comparators into x-ref-render-probe.jsonl and x-ftml-dump-probe.jsonl so the three sides are compared on identical inputs, and xcompare.py prints the three-way view.

X1 (live settled, candidate ftml divergence). A Comment span that hides the opener of a later Iftags block, `[!-- [[iftags +alpha]] --]body[[/iftags]]`, renders live as `<p>[!&#8212;</p>`; the reference produces the same bytes, while the shared ftml dumper produces `<p>body[[/iftags]]</p>`. Because Iftags runs before Comment in the reference pipeline, its recursive match consumes the hidden opener together with the closer and leaves the unterminated comment prefix for Typography; ftml's token-level pairing instead lets the comment elide its whole span first. This is a candidate ftml divergence for the coordinator, not a reference error on a live-settled shape. The same seam's opposite form, `[[iftags +alpha]]body[!-- [[/iftags]] --]tail`, is live/reference-identical as `<p>&#8212;]tail</p>` and differs from ftml only by the frame-level entity spelling `&#8212;` versus a literal em dash, which is a Typography/frame surface rather than a rule correction.

X2 (live settled, candidate ftml divergence). An Iframe call followed by URL syntax, either on the next line or the same line, is greedily absorbed by the reference so that the following `[[https://example.com/b]]` becomes part of the iframe src; live renders the identical greedy src (`src="https://example.com/a]][[https://example.com/b"`). The ftml dumper stops at the first closer and renders a normal iframe plus a link. ftml's own pin test/iframe/greedy-tail-iftags-nested-inside-failing/wikidot.html reproduces the greedy shape for a block-shaped tail, and the shared dumper reproduces that pin exactly, so this is a boundary of ftml's greedy-tail rule rather than a dumper artifact. The reference is live-correct here and was not corrected; route as a candidate ftml divergence and note that the Iframe owner's battery covers the same boundary.

X3 (live settled, reference surface correction owned by the Iframe owner). Live and ftml emit `<iframe ... style=""></iframe>` with no space before the closing `>`, including when the style attribute contains `url(...)`; the fossil render leaves one trailing space from its per-attribute loop. This is an Iframe render-rule correction, not a root finding; it is recorded here only so the interaction section can point to the owner's classification.

X4 (settled, suppression semantics). With a false Iftags gate, Module, Math and Date syntax inside the body is suppressed on all three sides (x-iftags-drop-module, x-iftags-drop-math, x-iftags-drop-date): the reference, ftml and live all render an empty page. The same holds for nested false gates. This confirms the stage's serving-layer boundary: suppressed content is never evaluated by later rules, and ftml pin test/iftags/false-gate-math-body-literal/wikidot.html agrees.

X5 (serving-layer surface, not a rule divergence). Math bodies behind a Comment-hidden closer and inside a Module body render as real equations live and in ftml, while the harness LatexRenderer stub deliberately takes the fossil failure path; that difference is the out-of-scope LaTeX image computation and is not corrected. Module bodies also show the already-routed rel="noopener noreferrer" difference from R2-MODULE.md M4. Frame-level spacing (`<br />` versus `<br>`, trailing block newlines) and the odate widget versus the fossil span are reported by the rule owners and are not re-adjudicated here.
