# CORRECTION-REFCORR64

REFCORR64 covers three measured remainder families: the authored U+FFFE/U+FFFF collision in REFCORR49's generated cross-line empty-raw mechanism, consecutive unknown-module error blocks inside one crossing anchor pair, and the exact block framing of unknown-module error output.

## Measured rules

Live preserves an authored adjacent U+FFFE U+FFFF sequence as written. This holds in a plain paragraph, in the inter-div blank-run context that motivated REFCORR49, inside a code block, in a longer noncharacter run, and when the two noncharacters are separated by other noncharacters. Live does not consume the authored adjacent pair as a space. The generated REFCORR49 cross-line empty raw still renders as one space in the same contexts.

When one anchor pair crosses consecutive unknown-module error blocks, live redistributes the anchor only inside the first error block's leading error text. The first block contains the crossing anchor around the literal module-error prefix and an empty copy of that anchor before the internal documentation link. The following error blocks are ordinary consecutive error blocks: live does not emit the reference's extra empty continuation anchors between them, and the crossing anchor does not continue into trailing text after the modules. For the visible Rate module, the same anchor structure is byte-exact after replacing only the harness `þmodule "Rate"þ` handoff marker with the captured live widget: the anchor wraps the whole widget and does not continue after it.

An unknown-module error div adjacent to plain paragraphs, with no anchor crossing, is block-level serving output. Live does not leave it inside a paragraph. The exact newline frame is the ordinary sibling-block frame in the measured separated shapes: one newline byte separates a preceding `</p>` from `<div class="error-block">`, one newline byte separates `</div>` from a following `<p>`, and adjacent error divs are likewise separated by one newline byte. This is parser/output repair behavior for error output the reference itself serves. Placeholder-rendered modules remain a serving-layer handoff boundary; the CSS module's empty body expansion is therefore not treated as proof that the fossil wire placeholder should be expanded by this parser harness.

## Implementation

The REFCORR49 temporary sentinel is now collision-proof. A generated cross-line empty raw writes the fixed internal noncharacter-byte sentinel `\xFE\xFE` instead of the authorable U+FFFE U+FFFF byte sequence. Raw byte FE is not valid UTF-8, so it cannot collide with a live-authored Unicode character, and it is not the parser token delimiter or a token id; it also does not consume or shift any real token id, which matters because some opaque module bodies leak token indexes. Divprefilter rewrites the fixed sentinel to spaces inside already-tokenized option strings, preserving the established module-body behavior, but leaves source occurrences intact so Size can still treat a cross-line empty raw as an empty raw atom while scanning. After Size finishes its scan it replaces remaining source occurrences of the fixed sentinel with one literal space. Authored U+FFFE/U+FFFF text is never matched by that replacement.

`Text_Wiki::redistributeAnchorAcrossOpaqueConstructs` now handles a run of consecutive unknown-module error blocks crossed by one anchor pair. It redistributes the crossing anchor inside the first block with the existing REFCORR61 rule, removes continuation anchors from subsequent adjacent unknown-module error blocks, and suppresses the trailing continuation paragraph when it is empty. Non-empty trailing text remains outside the anchor. The transformation is keyed only on the repeated anchor tag and unknown-module error-block structure, not on probe labels or page names.

The purification trigger now covers output containing the reference-served unknown-module error block. This is the byte-framing correction: unknown-module error output is block-level HTML generated by the serving path, so the same purifyHtml-equivalent repair path that live applies is required even when no anchor or other malformed crossing is present. Authored noncharacters need no special render-time trigger: once the generated sentinel no longer uses authorable bytes, the authored bytes pass through the ordinary token/text path unchanged.

## Boundary result

The CSS empty-module probe cell measures the serving layer's post-parser expansion whitespace. The parser harness intentionally exposes `þmodule ... þ` as the fossil handoff wire, so exact bytes through that placeholder are not a parser correction target in this round. The disclosed masked comparison is retained as an instrument result; it does not weaken the unknown-module error-div correction, which is byte-exact without any module-placeholder mask.
