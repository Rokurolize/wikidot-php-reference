- **Corrections (2)**, both in `ref-php/text-wiki/Text/Wiki/Render/Xhtml/File.php` (pre-correction backup `File.before-refval2.php`); the parse rule is unchanged:
  1. **Selective href encoding**: the file path now passes through a byte-wise encoder that percent-encodes only spaces and non-ASCII bytes (uppercase hex over the UTF-8 bytes), in both the page-qualified and bare-name branches. Everything else stays raw. Settled by `p15` (`my file.txt` -> `my%20file.txt`, `café.txt` -> `caf%C3%A9.txt`), `pf04` (space encoded in the qualified branch too), and the negative controls `pf01` (`+` raw), `pf02` (`%` raw), `pf03` (`#` raw). The fossil emitted the path completely raw.
  2. **Href and anchor escaping**: the href attribute value and the anchor text are now emitted through `htmlspecialchars(..., ENT_COMPAT, 'UTF-8')`; the fossil emitted both raw, producing malformed output such as `href="/a"b.txt"`. Settled by `p17` (href `a&quot;b.txt`, anchor `c&lt;d&gt;e`), `pf05` (`&` -> `&amp;` in both href and anchor), `pf06` (anchor apostrophe stays raw), and `ff01` (anchor double quotes -> `&quot;`).
- **Serving surface**: the bare-name branch's prefix is the application-supplied `base` config (in production, the current page's `/local--files/<page>/` on the site's wdfiles host); the harness leaves it at `/`, so probe comparison normalizes live's `https://sandbox-for-codex.wdfiles.com/local--files/<probe page>/` prefix away. The page-qualified branch's `/local--files/` prefix is the rule's own and matches live modulo the host alone. The parse behavior (pipe splitting including the `a.txt|` and `a|b|c` shapes, trimming, tag case-insensitivity, tab separator) already matched live on every probed shape.

After correction, the reference agrees with live on 20/20 probes, 6/6 supplementary probes, and `ff01`, under the base normalization above (`evidence/verify-refval2.py`).
