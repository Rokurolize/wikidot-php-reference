# Rule: Button (`[[button]]`, R3.17)

- **Battery**: 87 cases (`evidence/button/battery.jsonl`: 65 authored `bt-*` cases + 22 live probe cases `p01`..`p22`), plus supplementary live probes `sb01`..`sb08` (`evidence/button/supplementary.jsonl`; captures in `evidence/button/probes2-captures.json` and `evidence/button/probes4-captures.json`) and misc probes `fb01`/`fb02` (`evidence/button/probes5.jsonl`, captures in `evidence/button/probes5-captures.json`).
- **Live probes**: 22 pages `muse-probe-refval-button-p01`..`p22`, 8 pages `muse-probe-refval2-button-sb01`..`sb08`, and 2 pages `muse-probe-refval2-misc-fb01`/`fb02` on `sandbox-for-codex`, all with `saved_source_matches=true`, `valid=true`, `stable=true`.
- **Corrections (6)**, all in `ref-php/text-wiki/Text/Wiki/Render/Xhtml/Button.php` (pre-correction backup `Button.before-refval2.php`); the parse rule is unchanged:
  1. **Case-insensitive types**: `token()` now lowercases the type before the table lookups (the parse already maps `_` to `-`). Live accepts `[[button EDIT]]` and `[[button Edit_Sections]]` (settled by `p14`, `sb06`, `bt-06`, `bt-36`).
  2. **Six missing types** added to the allowed-types, default-text, and onclick tables: `rename` (`WIKIDOT.page.listeners.renamePage(event)`), `delete` (`deletePage(event)`), `parent` (`parentClick(event)`), `edit-meta` (`editMetaClick(event)`, default text `edit meta`), `watchers` (`watchersClick(event)`), and `set-tags` (`updateTagsByButton(event, '')`) (settled by `p06`, `p07`, `p08`).
  3. **History onclick**: removed the leading space in the fossil table's `' WIKIDOT.page.listeners.historyClick(event)'` (settled by `p03`, `bt-x03`).
  4. **Unknown-type error**: `The button type is not recognized` replaced by `<em>{type}</em> is not a valid button type`, where the type shown is the fully normalized type (lowercased, underscores as dashes) (settled by `p07` for `lock`, `p08` for `unknown-type`, `sb07` for `LOCK` rendering as `lock`, and `sb08` for `Foo_Bar` rendering as `foo-bar`).
  5. **set-tags text requirement**: `set-tags` without a `text` attribute renders `<div class="error-block">You need to set text for set-tags button.</div>`; with text, the onclick is `WIKIDOT.page.listeners.updateTagsByButton(event, '')` and the `tags` attribute is never rendered into the output under any shape (settled by `p06` and by `sb01`..`sb05`, five `tags` shapes — `"a b"`, `"+a -b"`, absent, `"a,b"`, `"one"` — all rendering the identical `''` argument). The reference drops `tags` at parse while live accepts and ignores it; the rendered output is identical either way.
  6. **Text escaping**: the button text now goes through `htmlspecialchars(..., ENT_COMPAT, 'UTF-8')` instead of the PHP 8.5 default flags, which spelled an apostrophe as `&#039;`; live spells it raw (settled by `p13`, `bt-x20`). This is the same era-artifact class the R2 Code stage corrected with explicit `ENT_COMPAT`.
- **Non-corrections**: the fossil template's trailing space before the anchor's closing `>` (`onclick="..." >`) is the known fossil-template space surface that live's Stage 2 tidies (the Div `<div >` precedent), not a defect. Attribute names are case-sensitive on live exactly as in the fossil's `getAttrs` (`fb01`/`fb02`: `Text=` and `TEXT=` are ignored and the default text renders), and unrecognized attributes are dropped by both sides (`p11`).
- **Comparison before vs. after**: before correction, 20 of 22 probes differed and 2 were trim-equal. After correction, the reference agrees with live on 22/22 probes and 8/8 supplementary probes under frame normalization (blank-line collapse plus the template-space and Stage 2 error-block paragraph surfaces; `evidence/verify-refval2.py`), and `fb01`/`fb02` agree exactly. Battery movement from the pre-correction renders is exactly 26 cases, each audited into one of the six correction classes: error wording (`bt-05`, `bt-07`, `bt-14`, `bt-15`, `bt-29`, `bt-32`, `bt-x15`, `bt-x22`), type case (`bt-06`, `bt-36`), history space (`bt-25`, `bt-x03`), the six new types (`bt-x10`..`bt-x14`, `bt-x16`, `bt-x17`, `p06`, `p07`, `p08`), and text escaping (`bt-x20`, `p13`, `p14`).
- **Smoke check**: 9/9 smoke cases byte-identical before and after the REFVAL2 corrections (swap-verified against the `*.before-refval2.php` copies).
- **R3 stage consequence**: none. `Parse/Default/Button.php` is untouched (the case normalization is render-side), so the R3.17 parse mirror stands as-is.
- **ftml candidates**: C-REFVAL2-3 (see REPORT-REFVAL2.md).
- **Verdict**: CORRECTED (6 corrections)
