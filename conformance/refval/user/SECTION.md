# Rule: User (`[[user]]` / `[[*user]]`, R3.17)

- **Battery**: 82 cases (`evidence/user/battery.jsonl`: 62 authored `us-*` cases + 20 live probe cases `p01`..`p20`).
- **Live probes**: 20 pages `muse-probe-refval-user-p01`..`p20` on `sandbox-for-codex`, all with `saved_source_matches=true`.
- **Environment-bound render**: `Render/Xhtml/User.php` resolves the user through `Criteria` and `DB_OzoneUserPeer::instance()->selectOne(...)` and renders a found user through `WDRenderUtils::renderUser(...)`; none of those classes exist anywhere in the reference tree, so 71 of the 82 battery cases produce the harness error record `Class "Criteria" not found`. The parse rule and the `WDStringUtils::toUnixName` normalization run before that point and are exercised. The found-user output is serving-layer by design on live as well (a `printuser` span whose link, user id, avatar URL, and resolved display name all come from the live user directory, e.g. `p13` resolves the name `a\nb` to the existing user "A B" and `p19` resolves `café` to "Cafe"), so no found-user rendering is expected from the reference.
- **Correction (1)** in `ref-php/text-wiki/Text/Wiki/Render/Xhtml/User.php` (pre-correction backup `User.before-refval2.php`): the not-found branch's message changed from `User <em>%s</em> can not be found.` with the raw user name substituted, to `<em>%s</em> does not match any existing user name` with the name escaped through `htmlspecialchars(..., ENT_COMPAT, 'UTF-8')`, inside the same `<span class="error-inline">` wrapper the fossil already had. The wording is settled by `p05`, `p06`, `p14`, `p17`; the escaping is settled by `p15`, where the name `<b>xss</b>` renders as `&lt;b&gt;xss&lt;/b&gt;` inside the message. Because the branch sits behind the environment-bound user lookup, the correction is verified against the live captures and the rule source; the battery shows zero movement, as expected.
- **Parse validation**: the parse rule matches live on every probed shape: plain and avatar (`*`) forms, display-name and unix-name inputs, case-insensitive tag and star placement (`p07`, `p08`), double-space, trailing-space, and tab separators (`p09`, `p10`, `p12`), a newline inside the name (`p13`), bracket edges (`p14`: `[[user a]b]]` literal, `[[user a]]]` tokenized with a trailing `]`), and inline position (`p18`).
- **Comparison before vs. after**: battery movement zero (both the pre-correction and corrected trees stop at the same environment boundary in-harness); probe adjudication rests on the parse agreement above plus the one corrected not-found string.
- **Smoke check**: 9/9 smoke cases byte-identical before and after the REFVAL2 corrections (swap-verified against the `*.before-refval2.php` copies).
