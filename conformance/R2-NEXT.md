# R2 Iftags, Comment, Iframe, Date, and Math stage: differential and correction catalog (2026-11-20)

Method. This stage runs as a team of five rule owners plus a root coordinator, one owner for each of the fifth-through-fifteenth pipeline rules in this batch: Iftags, Comment, Iframe, Date and Math. The shared reference harness (ref-php/harness/batch.php in render and tokens modes, transform.php for the smoke run) is read-only for rule owners; root built one shared ftml dumper at conformance-refphp/next/rust-dump/ in the Form/Raw stage's style (preprocess_for_layout, tokenize, parse, HtmlRender over JSONL {"id","source", optional "tags"}) and recorded the read-only ftml checkout HEAD 97bed049ddeadc54981f6d9577bd78fcb212abd9 (unchanged from the Module stage) in conformance-refphp/next/rust-dump/FTML-HEAD.txt before any differential started. Root also owns the shared OZONE stubs in ref-php/harness/ozone-stubs.php and the page map in pages.php, including any page-tags or date context a rule needs; a rule owner reports a stub need to root rather than editing shared files. For this stage root added three disclosed stubs: RefPage::getTagsAsArray() plus per-case "tags" injection in batch.php so Iftags can exercise both tag polarities against ftml's PageInfo.tags, a ProcessException class so Math's \include/\input rejection branch is a catchable reference error instead of a fatal, a no-op LatexRenderer::setDensity() after the Math owner reported that a following Mathinline call otherwise fataled on the shared stub (harness matter, not a rule correction), and no date context stub because the fossil Date matcher requires a numeric value and live's bare-date behavior is serving-layer scope. Root also declined a Date-owner request to renumber the shared Raw rule's document-local placeholders: live and ftml use document-local %FF<n>%FF indices while the fossil harness emits global token IDs, but changing the shared Raw rule would alter every previously completed stage's outputs, so it is disclosed here as a frame-level residual rather than normalized. Corrections land only in a rule's own Parse/Default/<Rule>.php and Render/Xhtml/<Rule>.php files, with pre-correction bytes preserved as conformance-refphp/next/<rule>/<File>.before.php before any edit. Each owner builds a battery of at least 40 cases, runs the harness (before and after correction) and the shared dumper over it, and probes saved anonymous page views on sandbox-for-codex.wikidot.com through the wikidot-probe CLI under its own disjoint prefix (muse-probe-r2next-iftags-, -comment-, -iframe-, -date-, -math-), fetching once and caching under its own evidence directory; root probes cross-rule interactions under muse-probe-r2next-x-. Evidence order when sides disagree is ftml corpus pins, then frozen captures, then live probes, and live behavior wins every disagreement; no ftml file is edited, and no git commit or git identity variable is used anywhere in this worktree. Serving-layer computation (the tag list of a real page, the current date for a bare date, LaTeX rendering for math) is evaluated only as far as live's anonymous saved-page view makes it observable and deterministic; the stage owns matching, tokenizing, argument and format handling and the observable display shape.
