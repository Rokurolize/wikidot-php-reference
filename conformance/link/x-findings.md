X1 (settled live, no divergence). Concatlines continuations inside Code, Raw, Rawold, Math and Comment spans are protected on all three sides: x-concat-code-inside, x-concat-raw-inside, x-concat-rawold-inside, x-concat-math-inside and x-concat-comment-inside agree after canonicalization. The reference achieves this because Code, Raw, Iftags, Comment and Math parse before Concatlines in the pipeline and have already replaced their spans with tokens; ftml achieves it because join_continued_lines in src/preproc/whitespace.rs excludes wikidot math and active code body ranges. A continuation crossing into a literal span is likewise settled: x-concat-comment-before, x-concat-comment-after and x-concat-raw-before-open agree on all three sides locally, and the protected-span probes carry the live evidence.

X2 (live settled, candidate ftml divergence, routed as M19). A continuation immediately before a Code opener, `a\` newline `[[code]]`, keeps the code block at line start on live and in the reference (live renders `<p>a</p>` followed by a real code block, byte-for-byte the reference shape after frame spacing), while the shared ftml dumper joins the continuation first and leaves `a[[code]]` as literal text. Evidence is the valid probe x-concat-code-before-open plus the ftml source: join_continued_lines runs in preprocessing before block parsing and only wikidot div openers have an explicit preservation test (wikidot_preserves_a_continued_standalone_div_boundary in src/preproc/whitespace.rs), so a code opener is swallowed by the join. This is a candidate ftml divergence for coordinator triage, not a reference error on a live-settled shape.

X3 (settled live in both Iftags polarities). A Freelink or an eref inside a suppressed Iftags body renders nothing on all three sides: the untagged probe x-free-iftags-drop-untagged and the tagged probe x-free-iftags-drop both have empty live HTML matching the reference and ftml. A true gate keeps the body and its inner constructs: tagged probes x-free-iftags-keep, x-eref-kept-math and the false-gate form x-eref-suppressed-math all agree on all three sides. Suppression is therefore settled in both polarities with tagged evidence, and no reference change was needed for these seams.

X4 (live settled, candidate ftml divergence, routed as M20). With two `[[math E]]` blocks and an `[[eref E]]` between them, live and the reference resolve the reference to the second (number 2), while ftml resolves it to the first (number 1). Evidence is the valid probe x-eref-duplicate-forward. The reference's Math parse registers labels in document order and last write wins; ftml preregisters named equations in document order but render_math_block re-registers each equation as it is rendered, so an eref encountered before the second block reads the first registration. With the eref after both blocks (x-eref-duplicate) all three sides agree on 2, so the divergence is specifically the mid-document forward-reference shape. This is a candidate ftml divergence, not a reference error on a live-settled shape.

X5 (settled live). Forward references with a single label are not a divergence: x-eref-forward and x-eref-backward agree on all three sides after canonicalization, and defined, undefined and duplicate-label trailing forms agree in the twelve-case set. Labels on equations suppressed by Iftags resolve to the empty-number anchor on all three sides (x-eref-suppressed-math), confirming that suppressed equations are never registered. Erefs inside Code, Raw and Comment spans stay literal on all three sides locally.

X6 (live settled, candidate ftml divergence, routed as M21). A Freelink embedded in a Math label position, `[[math [[[page]]]]]` followed by `[[eref [[[page]]]]]`, renders the math opener literally and the eref as an empty-number anchor on live and in the reference, while ftml leaves the whole eref call literal. Evidence is the valid probe x-free-math-label, the only one of the twenty cross-rule probes where reference and live agree against ftml. This is a tokenization-boundary candidate for ftml triage; the reference was not changed for it, and the surrounding math and freelink shapes separately agree on all three sides.
