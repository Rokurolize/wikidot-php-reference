# CORRECTION-REFCORR6-SRC — Mathinline recursive source-text expansion (2026-11-22)

C-SUSPECT3-1 is corrected on the reference side by carrying each token's exact authored source span from `addToken` onward and expanding it recursively at Mathinline time. The SUSPECT3 battery in conformance-suspect3/ (16 valid, stable, source-matching live captures in captures-m1.json, predictions in LEDGER-M1.md, verdicts in ADJUDICATION-M1.md) is the evidence. Live preserves the trimmed body verbatim, expands earlier-rule placeholders back to the original source text recursively, and suppresses the whole formula to `$$` when a Freelink, Raw, Newline or Image token occurs at any nesting level. The pre-correction reference resolved one level through option values, dropped a described email's address and brackets, leaked a nested placeholder as replacement bytes, and suppressed only first-level Newline and Raw.

Mechanism. `Text_Wiki::$tokenSource` is a side table keyed by token id, parallel to `$tokens`; `addToken` takes an optional fourth argument `$sourceText` and records it there without changing the compared `[rule, options]` token entry or the wire shape read by `state-restricted.php`. The claiming rule passes the exact span it replaced, taken from the `$matches` groups its callback actually received: Url inline claims the star plus group 3 (the leading prefix byte and the lazy trailing bytes are returned outside the token), Url described and `%%var%%` described claim the whole match, Email bare and described claim the whole match, Freelink claims the whole triple-bracket form, Newline claims only the LF after its prefix group, Image claims the whole `[[image ...]]` outside its alignment newlines, Code claims the whole match minus its trailing whitespace group, Raw's scanner claims the bytes it consumed, and Mathinline claims its whole `[[$ ... $]]` match. `Parse/Default/Mathinline.php` now walks every placeholder in the trimmed body with PREG_OFFSET_CAPTURE, checks the suppression set before any substitution, recurses into the stored source span with a per-chain cycle guard and a depth bound, leaves unknown placeholders literal, and falls back to the former one-level option replacement for a token with no recorded span. A suppression anywhere in the recursion empties the whole body. The URL described pass also yields a match that has swallowed the math closer's `$]` fragment (the m1-code shape), so Mathinline can claim the whole authored body instead of Url eating the math closer. The guard is narrowed to that fragment on purpose: an earlier `]]` version also stopped unrelated described URLs from claiming their spans and moved fifteen named r43 cases (inline3-xbattery/x101, four notes cases and ten prose cases), so it was reverted before the final gates.
